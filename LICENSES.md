# Licensing and attribution

## Proposed split license

- Original educational prose, diagrams and learning materials: **CC BY 4.0**.
- Original code examples and software: **MIT**.
- Third-party material: its original license and terms apply; inclusion in a reference list does not relicense it.

This is a proposal for maintainer confirmation before the first public release. Do not assume third-party repositories, logos, screenshots, datasets, papers or documentation can be copied into this project. Link to them, summarize in original wording, and preserve attribution. Record license and provenance for any incorporated asset.
