# Support and project questions

SoloFoundry is maintained as an open-source knowledge base. It does not provide consulting, legal/accounting advice, implementation support for a reader's product, or a response-time guarantee.

- Use a [content request](https://github.com/Chandanrohit/SoloFoundry/issues/new?template=content_request.md) for a missing topic or guide correction.
- Use GitHub Discussions if enabled for general learning questions; otherwise open an issue with a concise question and relevant public context.
- Report a potential security issue using [SECURITY.md](SECURITY.md), not a public issue.
- For time-sensitive claims, include the exact source, jurisdiction/version, and date you checked it.

Please do not include private customer information, credentials, or confidential documents in issues or pull requests.
