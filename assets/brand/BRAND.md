# SoloFoundry brand

- Name: SoloFoundry
- Tagline: Build with knowledge. Craft with purpose.
- Supporting line: An open-source workshop for independent builders.
- Symbol: an anvil struck by a hammer, creating sparks.
- Meaning: craft, deliberate effort, learning and transforming ideas into useful products.

## Primary palette
- Foundry Black: `#000000`
- Foundry Charcoal: `#171C25`
- Forged Brass: `#D69B55`
- Warm Stone: `#E9E2D6`
- Craft Green: `#617B70`

Use black or charcoal as the dominant background, brass for the symbol and emphasis, and warm stone for readable text. Maintain contrast. Avoid using the spark effect in tiny icons; simplify the mark for small sizes.

## Editable vector source

- `solofoundry-mark.svg` is a simple, editable anvil/hammer mark authored for this repository by SoloFoundry contributors on 2026-11-01. It is licensed under CC BY 4.0 with the other original educational brand artwork.
- The existing PNG renders are retained for compatibility. Their editable source files are not present in the repository; do not claim the SVG is the original source for those raster images.
- `site.css` applies the brand palette to the documentation site. Keep contrast readable in light and dark themes.
