# Product launch checklist

## Product and demand
- [ ] Target user and core problem are explicit
- [ ] MVP scope and non-goals are documented
- [ ] User workflows and failure states tested
- [ ] Pricing, terms and support path are clear

## Engineering and security
- [ ] Automated tests and rollback path
- [ ] Authentication, authorization and rate limits reviewed
- [ ] Secrets managed outside source control
- [ ] Dependencies and exposed services reviewed
- [ ] Data retention, deletion and backup policies defined
- [ ] Privacy and accessibility checks completed

## Operations
- [ ] Logs, metrics, alerts and owner defined
- [ ] Backups and restore tested
- [ ] Incident and support runbooks ready
- [ ] Capacity and cost limits understood

## Distribution and learning
- [ ] Positioning and onboarding ready
- [ ] Analytics events tied to product questions
- [ ] Feedback channel and changelog ready
- [ ] Launch experiment and success threshold defined
