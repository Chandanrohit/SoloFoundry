# Security policy

SoloFoundry is a documentation project, not a hosted product. This repository does not ask contributors to submit credentials, private customer records, or regulated data.

## Reporting a vulnerability

If you find a vulnerability in repository code, build automation, or a published example that could expose a real system, please use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, contact the repository owner through the GitHub profile and include only the minimum detail needed to establish a safe contact. Do not open a public issue with exploit details or personal data.

## Supported scope

We review the default branch and current documentation site workflow. Example code is educational unless a page explicitly says otherwise. A guide or checklist is not a security assessment or guarantee of compliance.

When reporting a problem, include affected path/commit, impact, safe reproduction steps, and any suggested mitigation. Avoid testing against systems you do not own or have permission to assess.
