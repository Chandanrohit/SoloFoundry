# Stack combinations

A stack is a set of interacting choices, not a popularity contest. For each combination document: target workload, team skill, deployment model, integration boundaries, data model, security posture, estimated cost drivers, maintenance burden, lock-in, scaling limits and migration path.

Compare a simple managed stack, a Python/API-centric stack, a TypeScript full-stack stack, a self-hosted/open-source stack and an AI-heavy stack. Include “do not use this stack when…” guidance.
