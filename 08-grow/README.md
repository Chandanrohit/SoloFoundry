# Growth and distribution

Growth starts with a clear audience, promise and credible path to reach users. Cover positioning, messaging, launch planning, content, SEO/GEO, communities, partnerships, outbound, product-led growth, onboarding, activation, retention, referrals, analytics and experimentation.

Do not confuse traffic with demand or signups with retained value. Tie each channel to a target segment, cost, conversion, payback period and learning objective.

## Learning path

1. [Positioning and messaging](positioning-and-messaging/README.md): state a testable audience, outcome, alternative, and evidence-backed difference.
2. [Distribution and launch experiments](distribution-and-launch-experiments/README.md): pick a channel, measure downstream user outcomes, and plan a safe launch.
3. Use the [growth experiment template](../templates/GROWTH_EXPERIMENT.md); connect results back to [discovery evidence](../01-discover/assumptions-and-evidence/README.md).

No positioning hypothesis or channel in these guides has been validated for a real product. Search guidance changes; links are to official Google Search Central documentation and should be rechecked when used.
