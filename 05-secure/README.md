# Security and privacy

Security is a lifecycle discipline. Cover threat modeling, secure design, identity and access management, secrets, encryption, input validation, dependency and supply-chain security, application security testing, data classification, privacy, retention, incident response and compliance scoping.

Use recognized standards and primary references (for example OWASP projects, NIST publications and applicable legal texts). Distinguish general engineering guidance from legal advice. Do not claim compliance from a checklist alone.

Start with [secure product engineering](secure-product-engineering/README.md) and the [threat model template](../templates/THREAT_MODEL.md). Continue through [deployment and release](../06-deploy/deployment-and-release/README.md) and [reliability and recovery](../07-operate/reliability-and-recovery/README.md). The guidance is a method synthesis; no product has been assessed.
