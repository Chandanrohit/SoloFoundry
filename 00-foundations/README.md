# Foundations

The independent-builder mindset is not “do everything alone.” It is the ability to understand a problem, make informed decisions, use tools and collaborators effectively, and recognize when specialist expertise is needed.

## Core capabilities
- Systems thinking and first-principles reasoning
- Learning how to learn; reading documentation and research
- Technical and product decision-making
- Scope control, prioritization and risk management
- Communication, documentation and responsible collaboration
- Ethical, secure and sustainable building

## Decision rule
Start from user needs and constraints. Select the simplest approach that satisfies them. Add complexity only when evidence justifies it.
