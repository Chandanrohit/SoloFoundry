# Product design

Translate validated problems into a clear product promise and usable workflow. Include product strategy, product briefs, PRDs, user stories, journey maps, information architecture, wireframes, prototyping, usability research, visual systems, content design and accessibility.

Design for the user's task and context—not for feature count. Include empty, loading, error, offline, permission, recovery and edge states. Treat accessibility (keyboard, semantics, contrast, motion, assistive technology) as a baseline.
