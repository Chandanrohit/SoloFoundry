# Industry playbooks

Each industry playbook must connect domain context to a real problem and an implementable product: workflows, users, buyer, regulations, data sources, integration landscape, architecture, AI suitability, security, procurement, economics, deployment and validation.

Starter domains: [FinTech](fintech/README.md), [Healthcare](healthcare/README.md), [LegalTech](legaltech/README.md), [Manufacturing](manufacturing/README.md), [Retail](retail/README.md), [Education](education/README.md).
