# Product engineering

Build maintainable software around explicit requirements and operational constraints.

## Domains
- Frontend: rendering, state, routing, forms, accessibility, performance.
- Backend: domain logic, services, queues, caching, auth, validation and resilience.
- Data: relational/document/key-value/time-series stores, transactions, indexing, migrations, backup and retention.
- APIs and integration: REST, GraphQL, gRPC, webhooks, versioning, idempotency and rate limits.
- Architecture: modular monoliths, service-oriented systems, event-driven systems, serverless and microservices.
- Quality: unit, integration, contract, end-to-end, load, chaos and security testing.

Do not default to microservices, Kubernetes, Kafka or a vector database. State the requirement that justifies each operational dependency.
